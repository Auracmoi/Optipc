# Phase 2 — Tests avec 8 à 10 personnes (5 déc → 18 déc)

[← Index](../INDEX.md)

Objectif : savoir si des gens règlent un vrai problème avec OptiPC plutôt qu'avec Windows ou CCleaner. Fin visée : 18 déc. 2026.

1. Recruter 8 à 10 personnes ayant eu récemment un disque plein ou un PC lent.
2. Avant toute démo, leur faire classer leurs problèmes de PC, puis raconter ce qu'elles ont fait la dernière fois.
3. Les observer régler ce problème avec leur outil habituel, puis avec OptiPC (machine de test ou sous supervision, mode lecture seule d'abord).
4. Présenter l'une des deux phrases (moitié du groupe chacune) et leur demander de la reformuler :
    - « Voyez ce qui remplit votre disque, nettoyez sans risque, vérifiez l'espace récupéré »
    - « Trouvez les programmes qui ralentissent votre démarrage, désactivez-en un, réactivez-le si besoin »
5. Les recontacter une semaine plus tard : ont-elles réutilisé l'app, ou l'ont-elles conseillée ?

Ne jamais demander à un testeur de passer outre l'alerte SmartScreen juste pour finir le test.

| Ce qu'on note pour chaque testeur | Pourquoi |
| --- | --- |
| Étape d'abandon : téléchargement, SmartScreen, droits admin, diagnostic, aperçu | Indique quel blocage corriger en premier |
| Correction terminée et vérifiée (espace libéré mesuré, programme désactivé puis rétabli) | Le vrai indicateur, pas le nombre de téléchargements |
| Problème qui l'a amené (disque ou lenteur) | Choisir le parcours à approfondir |
| Réutilisation ou recommandation à J+7 | Distinguer l'intérêt poli d'un vrai besoin |
