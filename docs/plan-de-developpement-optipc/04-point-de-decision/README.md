# Point de décision (vers le 19 déc)

[← Index](../INDEX.md)

La phase 3 démarre seulement si les résultats de la phase 2 le justifient. Les seuils ci-dessous sont des propositions à ajuster.

| Résultat des tests | Décision |
| --- | --- |
| Au moins 5 testeurs sur 10 terminent une correction vérifiée, et au moins 3 réutilisent l'app à J+7 | Phase 3 : lancement public sur le parcours gagnant |
| Les testeurs veulent la correction mais s'arrêtent à SmartScreen | Signature de code et installateur en priorité, puis nouveau test |
| Les testeurs atteignent l'aperçu mais préfèrent leurs outils Windows | Changer la correction proposée ou le public, nouvelles interviews, pas de nouvelle fonction |
| Le problème n'est pas dans leur top 3 | Revoir le public visé avant tout développement |
